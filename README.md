# 森林景观恢复承诺与社区收益核证

跟踪森林景观恢复地块、权利、监测、灾害和社区收益。

## 参与方与事实

主要参与方包括景观恢复计划秘书处、地方社区和土地权利人、实施机构、生态监测团队、出资与审核人员。领域资料记录以下已经确认的事实：

- 全球有超过4.6亿公顷森林处于退化状态
- 91个国家和地区承诺恢复超过1.9亿公顷森林
- 报告强调当地民众参与、权利保障和长期融资

## 业务约束

- 地块和权利基线
- 恢复承诺
- 监测核证
- 灾害与补植
- 资金和社区收益

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/news_context_003.py` 负责读取和校验这些资料。`src/restoration_service.py` 在此之上实现承诺申报、监测核证、灾害补植、付款审批与审计解释的完整服务，设计要点见 `docs/service-design.md`。

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

两条命令只读取仓库内文件，不需要连接外部业务系统。
